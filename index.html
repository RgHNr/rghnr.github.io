Strategic Cannon Puzzle

Unity · C# · Editor Scripting · Firebase
My role: Solo Indie Developer. Built the custom level design tool, modular game architecture, Firebase live-ops backend, rendering optimization, and inventory system.

A grid-based mobile puzzle built around a custom level-design pipeline, live-ops rewards, and a deep inventory meta.

What I built
  • Custom Level Design Tool: a Unity Editor Window (LevelMakerTool) with paint-based grid UI & ScriptableObject serialization.
  • Rendering optimization: used MaterialPropertyBlock for dynamic block/cannon colors, avoiding runtime material instances and preserving draw-call batching.
  • Modular architecture: decoupled GridManager, InventoryManager & SlotManager with event-driven logic; column shifting & recursive block fusing tweened via DOTween.
  • Live-ops backend: Firebase Anonymous Auth for onboarding + Remote Config to balance daily coin rewards without app updates.
  • Inventory system: supports multi-slot linked items with adjacent-slot detection, sorting & merging mechanics.
Cut level creation time from ~20 min to under 2 min (90% faster).
